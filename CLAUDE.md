## Database

- Two Supabase projects: the real one (`.env.local`, also used by Vercel previews) and a test one (`.env.test.local`, e2e only).
- The agent cannot run DDL. Write the migration in `supabase/migrations/NNNN_name.sql`, then ask Dorian to paste it into the SQL editor of **both** projects. Check it landed with a read through supabase-js.
- This project turns off automatic API grants. Every new table needs RLS on, no policies, and `grant select, insert, update, delete ... to service_role`. Every new function needs `revoke execute ... from public, anon, authenticated` and `grant execute ... to service_role`.
- `npm run seed` loads `content/guests.ts` into the real database. It deletes rows that are no longer in content, so ask before running it.
- To unlock Dorian from a phone, Dorian runs a saved SQL snippet in Supabase (clears `failed_attempts`, `locked_until`, `admin_failed_attempts`, `admin_locked_until`).

## Tests

- `npm test`: Vitest, `lib/**/*.test.ts` only.
- `npm run e2e`: Playwright on iPhone 16 (WebKit) and Pixel 9 (Chromium). It builds and starts its own server on port 3020 with test-only env (`e2e/env.ts`), and loads fixtures into the test database. It refuses to run if `.env.test.local` points at the real database.
- New tables need fixture and reset updates in `e2e/db.ts`.
- `E2E_INSECURE_COOKIES=1` exists only for the test server, because WebKit refuses `Secure` cookies on `http://localhost`. Never set it in Vercel.
- Wait for a server action's POST before the next step (`submitAction` in `e2e/helpers.ts`), or the navigation aborts it.
- Screenshots go to `test-results/screens/`. Take viewport shots, not full-page (full-page misplaces the fixed tab bar).
- What tests cannot cover: the deployed Vercel build (previews sit behind Vercel login and use the real database) and other phone apps (Calendar). Those are Dorian's phone checks.

## Next.js 16 quirks

- Cache Components is on. `export const dynamic` is not allowed: call `await connection()` instead. Dynamic reads (cookies, database) go inside `<Suspense>`.
- Middleware is `proxy.ts` (Node runtime). It gates every page behind the `event` cookie, except `/api/health`, the link-preview image and build assets.
- `refresh()` comes from `next/cache`. `PageProps<'/route'>` types are generated by the build.
- After switching branches, stale `.next/types` break `tsc`. Run `rm -rf .next && npm run build`.
- Next.js expands `$NAME` in `.env` files, so stored hashes use `:` separators.

## UI conventions

- Tokens only (`app/globals.css`), never raw hex in components. The default Tailwind palette is removed.
- More (`/more`) has guest links, then an "Organizer" section (only for `is_admin`) with one link per admin page. Add every new admin page to `lib/organizer.ts`: More and `/admin` both list from it. Admin pages call `requireAdmin('/admin/...')`, so the 12-hour PIN prompt returns there. Pages reached from More use `<PageShell active="more">`.
- Check new screens at phone size (375 to 393 points wide). The fixed tab bar must never hide a primary button.
